# 预实现：相似图片搜索 — 页内跳转 + 高亮

## 现状

`SearchSimilarAsync` 将搜索结果放入独立页面（`IsShowingSearchResult = true`），脱离原文件夹浏览上下文。

## 目标

对以图搜图，不再另起空页面，而是跳转到相似图所在的文件夹分页，并用蓝色选中框高亮所有找到的相似图片。

## 涉及文件

- `src/ImageManager.App/ViewModels/MainWindowViewModel.cs`
  - `SearchSimilarAsync` — 核心改动
  - `ShowPageAsync` / `CreatePlaceholderItems` — 可能需要配合

## 实现思路

### SearchSimilarAsync 改写

```
1. 调用 _similarService.FindSimilarAsync(...) 获取结果
2. _searchResultFiles = results（保存全部相似路径，不设 IsShowingSearchResult）
3. 找到第一个非搜索目标本身的路径 → 计算其在 _allFiles 中的 index
4. int targetPage = index / PageSize
5. 重置 TotalPages/PageNumbers（基于 _allFiles，不是搜索结果）
6. 清空 _pageCache
7. await ShowPageAsync(targetPage)
8. 遍历 Images，路径在 _searchResultFiles 中的设置 IsSelected = true
9. StatusText = $"找到 {count} 张相似图片（已跳转到第 {targetPage + 1} 页）"
```

### CreatePlaceholderItems 配合

当前 `CreatePlaceholderItems` 不检查 `_searchResultFiles`。若用户跳转页面后相似图跨页，切换页面时新 item 不会被选中。需要在该方法末尾检查：

```csharp
if (_searchResultFiles.Count > 0)
{
    var similarSet = new HashSet<string>(_searchResultFiles, StringComparer.OrdinalIgnoreCase);
    foreach (var item in list)
    {
        if (similarSet.Contains(item.FilePath))
            item.IsSelected = true;
    }
}
```

### 与 Tag 搜索的隔离

- Tag 搜索继续使用 `IsShowingSearchResult = true`，独立搜索结果页
- 相似搜索不设 `IsShowingSearchResult`，保持在文件夹视图内
- `BackFromSearch` 的 `IsShowingSearchResult` 守卫天然跳过相似搜索路径

### 注意事项

1. 相似图可能跨多页，只有当前页的会被高亮。状态栏文字提示总数即可。
2. 跳转后切页会触发 `CreatePlaceholderItems` 重建 item，需要 `_searchResultFiles` 配合延续高亮。
3. 从搜索返回时需清空 `_searchResultFiles` 和 item 的 `IsSelected`，避免残留高亮。
4. 取消搜索（`StopSearch`）目前为空实现，后续可加上取消高亮的逻辑。
