# ImageManager2 — 测试计划与报告

## 1. 概述

### 1.1 测试目标
确保 ImageManager2 在功能正确性、性能指标和稳定性方面满足需求规格说明书中定义的标准。

### 1.2 测试范围
- 功能测试：所有 FR-1 ~ FR-12 需求项
- 性能测试：缩略图加载、翻页、哈希计算、内存占用
- 兼容性测试：Windows 10/11
- 数据迁移测试：旧版 JSON → SQLite

### 1.3 测试环境
- OS: Windows 10 Pro 22H2 / Windows 11
- .NET Runtime: 8.0.x
- 测试数据: 100 ~ 10,000 张混合图片 (JPEG/PNG/GIF/BMP/WebP)

## 2. 测试策略

### 2.1 测试级别

| 级别 | 覆盖率目标 | 方法 |
|------|-----------|------|
| 单元测试 | 服务层/算法层 80%+ | xUnit + Moq |
| 集成测试 | Repository 层 60%+ | 真实 SQLite 内存数据库 |
| 手动测试 | UI 层全功能 | 功能验证清单 |
| 性能测试 | 关键路径 | BenchmarkDotNet |

### 2.2 当前测试状态
本项目目前采用手动功能验证为主，单元测试框架尚未搭建。以下测试用例基于手动验证清单。

## 4. 性能测试指标

| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 首屏加载 (200 缩略图) | < 2s (首次) / < 500ms (缓存命中) | Stopwatch 计时 |
| 翻页延迟 (缓存未命中) | < 1s | Stopwatch 计时 |
| 翻页延迟 (缓存命中) | < 200ms | Stopwatch 计时 |
| 感知哈希计算 (单张) | < 50ms | 批量平均值 |
| 相似搜索 (1000 张) | < 5s | Stopwatch 计时 |
| 应用启动时间 | < 3s | Stopwatch 计时 |
| 内存占用 (10,000 张) | < 500MB | Task Manager |
| 数据库大小 (10,000 张) | < 30MB | 文件属性 |
