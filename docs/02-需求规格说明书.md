# ImageManager2 — 需求规格说明书 (SRS)

## 1. 引言

### 1.1 文档目的
本文档定义 ImageManager2 图片管理系统的功能需求和非功能需求，作为设计、开发和测试的依据。

### 1.2 适用范围
本文档涵盖 ImageManager2 v1.0 的所有用户可见功能及系统内部约束。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| **感知哈希 (Perceptual Hash)** | 基于图像视觉特征的指纹算法，相似图像产生相近的哈希值 |
| **瀑布流 (Waterfall)** | 不等高图片的紧凑排列布局 |
| **共现标签 (Co-occurring Tag)** | 在当前搜索结果中出现频率最高的标签，用于二次筛选 |
| **标签搜索运算符** | 用于组合多个标签的逻辑运算符 (a/o/e/-) |
| **WAL 模式** | SQLite 的 Write-Ahead Logging，允许并发读写 |

## 2. 总体描述

### 2.1 产品概述
ImageManager2 是一款 Windows 桌面图片管理工具。用户通过文件夹组织图片，通过标签系统进行分类和检索，支持精确去重和相似图片查找，并集成在线以图搜图功能。

### 2.2 用户角色

| 角色 | 描述 |
|------|------|
| **普通用户** | 浏览、搜索、管理本地图片库 |
| **高级用户** | 使用标签运算符进行复杂搜索，自定义快捷键和布局参数 |

### 2.3 运行环境
- **操作系统**：Windows 10/11 (主要目标), macOS, Linux
- **运行时**：.NET 8 Desktop Runtime
- **数据库**：SQLite 3.x (嵌入式，无需安装)
- **磁盘空间**：数据库 < 100MB，缩略图缓存 < 用户配置上限

## 3. 功能需求

### FR-1: 文件夹管理

**FR-1.1 添加文件夹**
- 用户选择本地文件夹加入管理列表
- 系统扫描文件夹内所有图片格式文件（.jpg/.jpeg/.png/.gif/.bmp/.webp/.tiff）
- 自动分配 FolderId 索引以加速查询
- 记录文件夹别名和排序位置

**FR-1.2 移除文件夹**
- 从管理列表移除文件夹
- 不清除该文件夹图片的数据库记录（仅解除关联）
- 清理该文件夹下所有图片的磁盘缩略图缓存

**FR-1.3 文件夹别名**
- 用户可为文件夹设置自定义显示名称
- 别名显示在侧边栏（优先于文件夹名）

**FR-1.4 文件夹搜索**
- 侧边栏提供文件夹名搜索输入框
- 实时过滤显示匹配的文件夹

**FR-1.5 文件夹重定位**
- 当文件夹在文件系统中被移动后，更新数据库中所有对应图片的路径
- 采用前缀替换策略批量更新

**FR-1.6 文件夹实时监控**
- 使用 FileSystemWatcher 监控当前选中文件夹
- 检测新增文件和删除文件事件
- 2 秒防抖后自动触发同步（重新扫描 + 哈希补算）
- 拖拽外部图片到文件夹列表同样触发同步

### FR-2: 图片浏览

**FR-2.1 分页加载**
- 每页固定 200 张图片
- 仅加载当前页 + 相邻 2 页（最多缓存 3 页）
- 翻页时优先使用缓存，未命中则重新创建占位 item
- 页码下拉框支持直接跳转
- 显示当前页/总页数及加载状态信息

**FR-2.2 缩略图显示**
- 支持 JPEG 缩略图实时生成
- 占位 item 先显示确定性背景色（文件名哈希 → 柔和彩色），加载完成后替换为实际缩略图
- 显示图片文件名（可配置开关）
- 显示图片标签摘要（可配置开关）
- 显示图片方向标识（横图/竖图）（可配置开关）

**FR-2.3 瀑布流布局**
- **网格模式 (Grid)**：固定单元格，左到右换行
- **垂直瀑布流 (Vertical Masonry)**：不等高，最短列优先放入
- **水平自适应 (Horizontal Justified)**：按行高自适应宽度填充
- 三种模式可通过菜单/快捷键切换

**FR-2.4 缩放控制**
- 提供 10 级离散缩放（缩略图基准宽度 160px ~ 640px）
- 滑块拖动平滑过渡，300ms 防抖触发缩略图重建
- 不同瀑布流模式独立记录缩放级别

**FR-2.5 图片排序**
- 按文件名（升序/降序）
- 按修改时间（升序/降序）
- 按文件大小（升序/降序）
- 按分辨率（宽 × 高）（升序/降序）

**FR-2.6 方向筛选**
- 全部 / 仅横图（宽 > 高）/ 仅竖图（高 > 宽）
- 三个按钮互斥切换

### FR-3: 图片预览

**FR-3.1 全屏预览**
- 点击缩略图打开预览窗口
- 支持鼠标滚轮缩放（以光标位置为中心）
- 支持鼠标拖拽平移
- 键盘左右箭头切换上/下一张
- Esc 或退格键关闭预览

**FR-3.2 预览信息**
- 显示文件名、分辨率、文件大小
- 显示当前图片在文件夹中的位置（如 "第 15/200 张"）
- 显示关联标签

**FR-3.3 预览窗口记忆**
- 记住上次关闭时窗口位置和尺寸
- 下次打开恢复

### FR-4: 标签系统

**FR-4.1 标签编辑**
- 为选中图片添加/删除标签
- 标签输入框自动补全（前缀匹配，显示使用次数）
- 收藏标签快速选择
- 可为单张或多张图片同时设置标签

**FR-4.2 标签重命名**
- 全局重命名标签（所有关联图片同步更新）
- 冲突检测：若目标名称已存在，提示用户选择合并或取消

**FR-4.3 标签合并**
- 将标签 A 的所有关联图片迁移到标签 B
- 删除标签 A
- 用于消除重复/近似标签

**FR-4.4 收藏标签**
- 用户可将常用标签加入收藏
- 收藏标签在标签编辑窗口优先显示
- 收藏标签在搜索框下拉中优先排列

**FR-4.5 保留标签名**
- 搜索运算符 "a", "o", "e" 为系统保留字，不可作为标签名

### FR-5: 标签搜索

**FR-5.1 搜索运算符**
| 运算符 | 含义 | SQL 逻辑 |
|--------|------|----------|
| `a` | 同时包含所有指定标签 | AND（HAVING COUNT = N） |
| `o` | 包含任一指定标签 | OR |
| `e` | 分别查找每个标签（交集） | AND-each |
| `-` | 排除含此标签的图片 | NOT IN 子查询 |
| `关键字`（无运算符） | 标签名前缀搜索，弹出联想下拉 | LIKE %keyword% |

**FR-5.2 组合搜索**
- 支持多运算符混合：如 `a 角色 o 场景 - 废稿`
- 输入框边框颜色随激活的运算符变化（红=排除，蓝=AND-each，绿=AND）

**FR-5.3 未标记筛选**
- 特殊关键字 `-every`：查找没有任何标签的图片
- SQL: `WHERE Id NOT IN (SELECT ImageMetaId FROM ImageTag)`

**FR-5.4 共现标签模式**
- 标签搜索完成后进入 co-tag 模式
- 显示当前搜索结果中最常见的其他标签
- 点击共现标签循环切换状态：
  - 第 1 次: AND (绿色) → 进一步限定
  - 第 2 次: AND-each (蓝色) → 分别匹配
  - 第 3 次: NOT (红色) → 排除
  - 第 4 次: 移除

**FR-5.5 搜索结果管理**
- 标签搜索结果进入独立结果页面（IsShowingSearchResult = true）
- "返回" 按钮清除筛选，恢复搜索前的文件夹浏览状态（页码、滚动位置）
- 搜索结果保持原有排序

### FR-6: 相似图片搜索

**FR-6.1 以图搜图**
- 右键菜单选择 "查找相似图片（本地）"
- 或将图片拖拽到搜索区域
- 使用感知哈希多算法投票判定相似度
- 结果在当前文件夹内跳转到相似图所在页
- 相似图片使用蓝色选中框高亮
- 状态栏显示找到的相似图片数量

**FR-6.2 相似度算法**
- 第一阶段：颜色直方图交集（阈值 0.35），快速过滤不相似图片
- 第二阶段：多哈希投票（aHash 距离 ≤8, dHash 距离 ≤8, wHash 距离 ≤10），需 2/3 通过
- 支持取消搜索（StopSearch）

### FR-7: 在线以图搜图

**FR-7.1 支持的搜索引擎**
| 引擎 | 方式 | 描述 |
|------|------|------|
| SauceNAO | HTTP POST 上传 | 动漫/插画图片来源查询 |
| IQDB | HTTP POST 上传 | 二次元图片搜索 |
| Trace.moe | JSON API | 动画场景识别 |
| ASCII2D | 首页跳转 | 二次元图片来源 |
| Google | 首页跳转 | 通用以图搜图 |
| Yandex | 首页跳转 | 俄语区以图搜图 |
| Baidu | 首页跳转 | 中文区以图搜图 |
| Soutubot | 首页跳转 | Telegram 机器人 |
| Yandere | 首页跳转 | 动漫图库搜索 |

**FR-7.2 上传模式**
- 使用 MultipartFormDataContent 上传
- 自动处理 HTTP 重定向
- 搜索结果在默认浏览器自动打开

### FR-8: 重复图片检测

**FR-8.1 精确去重**
- 基于 MD5 文件哈希分组
- 每组保留最大分辨率（宽 × 高）图片
- 其余重复图片移动到指定目标文件夹
- 移动后自动更新数据库文件路径
- 显示处理结果统计

**FR-8.2 模糊去重**
- 预留接口，当前未实现（fuzzyCount 始终为 0）

### FR-9: 系统设置

**FR-9.1 外观设置**
- 深色模式 / 浅色模式切换
- 一次切换即时生效，所有窗口同步更新

**FR-9.2 缩略图设置**
- 显示/隐藏文件名、标签、方向标识
- 自定义边框颜色、背景颜色（支持透明度）
- 自定义圆角半径
- 自定义宽高比（默认 1:1）
- 无文字时的图片拉伸模式和留白开关
- 缩略图整体不透明度

**FR-9.3 壁纸设置**
- 选择本地图片作为窗口背景
- 支持拉伸模式（UniformToFill/Uniform/Fill/None）
- 支持对齐方式（9 个方位）
- 支持透明度调节
- 实时预览

**FR-9.4 内存与缓存设置**
- 内存缓存上限（64 ~ 4096 MB）
- 磁盘缓存路径自定义
- 显示当前内存/磁盘缓存使用量

**FR-9.5 快捷键设置**
- 可自定义功能快捷键
- 点击快捷键项进入录制模式
- 显示默认值和当前值
- 支持单个重置和一键全部重置

### FR-10: 数据交互

**FR-10.1 剪贴板操作**
- 右键单张复制到剪贴板
- Ctrl+C 批量复制选中图片
- 使用文件拖放格式（SetFilesAsync），可在 QQ/资源管理器直接粘贴

**FR-10.2 拖拽导出**
- 从缩略图网格拖拽图片到资源管理器或聊天窗口
- 批量解析 IStorageFile 实现

**FR-10.3 右键打开**
- 在资源管理器中打开（定位到文件）
- 删除文件（移到回收站或永久删除，同步清理数据库和缓存）

### FR-11: 数据迁移

**FR-11.1 旧版兼容**
- 支持导入旧版 WPF ImageManager 的 `image_data.json` 数据文件
- 迁移内容包括：图片元数据、标签、文件夹、收藏标签、设置项
- 迁移后显示统计摘要

### FR-12: 帮助系统

**FR-12.1 帮助窗口**
- 展示完整标签搜索规则语法
- 展示共现标签模式操作方法
- 列出所有快捷键
- 静态文本，从菜单栏 "设置 → 帮助" 打开

## 4. 非功能需求

### NFR-1: 性能

| 指标 | 要求 |
|------|------|
| 缩略图首屏加载 | < 500ms（200 个缩略图） |
| 翻页响应 | < 200ms（缓存命中）、< 1s（缓存未命中） |
| 哈希计算 | 每张 < 50ms（平均），利用多核并行 |
| 内存占用 | < 500MB（万级图片库） |
| 启动时间 | < 3s |
| 数据库查询 | 标签搜索 < 1s，计数查询 < 100ms |

### NFR-2: 可用性
- 关键操作不阻塞 UI 线程（所有 I/O 和计算异步执行）
- 提供加载状态指示（占位颜色 → 缩略图）
- 错误操作有明确反馈（如标签重命名冲突提示）
- 符合 Windows 桌面应用操作习惯

### NFR-3: 可靠性
- 崩溃日志自动写入桌面 `ImageManager_crash.log`
- SQLite WAL 模式保证崩溃后数据完整性
- 文件操作失败不导致数据不一致
- 哈希预计算失败不阻塞正常浏览

### NFR-4: 可维护性
- 四层架构（Common/Core/Infrastructure/App）职责清晰
- 服务接口与实现分离，可单元测试
- MVVM 模式分离 UI 和业务逻辑
- 关键算法（哈希、缓存、搜索）独立封装

### NFR-5: 可扩展性
- 服务接口注入，新功能通过实现新接口扩展
- AppSettings 基于反射序列化，新增配置项无需改数据库 Schema
- PageManager/TagSearchController 独立于 MainWindowViewModel，可独立演化

## 5. 接口需求

### IR-1: 数据库接口
- SQLite 数据库路径：`%LocalAppData%/ImageManager/data.db`
- 所有 Repository 通过 Dapper 执行原始 SQL
- 连接字符串在 AppDbContext 中统一管理

### IR-2: 文件系统接口
- 缩略图磁盘缓存路径：用户可配置，默认 `C:\ImageManagerCache`
- 缓存文件命名：MD5(小写路径).jpg
- 按解码宽度分目录：`w200/`, `w400/` 等

### IR-3: 在线搜索接口
- SauceNAO: `https://saucenao.com/search.php`
- IQDB: `https://iqdb.org/`
- Trace.moe: `https://api.trace.moe/search`
- 超时时间：30 秒
