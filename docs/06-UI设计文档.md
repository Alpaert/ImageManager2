# ImageManager2 — UI 设计文档

## 1. 概述

ImageManager2 基于 Avalonia Fluent 主题构建，采用标准桌面应用布局模式。UI 设计遵循以下原则：
- 左侧导航 + 右侧内容的经典双栏布局
- 深色/浅色双主题，通过 DynamicResource 全局切换
- 所有颜色通过 `App.ApplyColors(bool dark)` 集中定义

## 2. 窗口层级

```
MainWindow (主窗口)
├── 菜单栏 (Menu)
│   ├── 设置菜单
│   │   ├── 窗口大小 → SizeSettingWindow (模态对话框)
│   │   ├── 外观设置 → AppearanceSettingWindow (模态对话框)
│   │   ├── 壁纸设置 → WallpaperSettingWindow (模态对话框)
│   │   ├── 缩略图设置 → ThumbnailSettingWindow (模态对话框)
│   │   ├── 内存与缓存 → MemorySettingWindow (模态对话框)
│   │   ├── 快捷键设置 → ShortcutSettingWindow (模态对话框)
│   │   └── 帮助 → HelpWindow (模态对话框)
│   └── 排序菜单 (8 种排序方式)
├── 侧边栏 (文件夹列表 + 搜索)
└── 主内容区
    ├── 工具栏 1 (按钮 + 状态文本)
    ├── 工具栏 2 (标签搜索 + 方向筛选 + 拖拽搜索区)
    ├── 工具栏 3 (分页导航 + 缩放滑块)
    └── 图片网格 (SmartWaterfallPanel)

PreviewWindow (独立窗口, 非模态或模态)
└── 图片预览 + 导航箭头

TagEditWindow (模态对话框)
├── 左侧: 自动补全建议
├── 中间: 当前标签
└── 右侧: 收藏标签

RenameTagWindow (模态对话框, 从 TagEditWindow 唤起)
└── 新名称输入框
```

### 3.2 侧边栏

- 宽度：230px 固定
- 顶部：添加(+) 和 删除(-) 按钮
- 中部：文件夹搜索 TextBox
- 列表：ListBox 显示 FolderInfo.DisplayName
- 右键菜单：重命名别名 / 清除别名
- 支持拖拽图片到文件夹（触发文件夹同步）

### 3.3 缩略图模板

```
┌──────────────────┐
│ 背景色 (占位)     │  ← PlaceholderColor (文件名哈希 → HSL 柔和色)
│                  │
│   ┌──────────┐   │
│   │          │   │
│   │ 缩略图   │   │  ← 加载完成后替换背景
│   │          │   │
│   └──────────┘   │
│ 文件名.jpg       │  ← ShowThumbnailFileName 控制
│ 角色, 场景       │  ← ShowThumbnailTags 控制
│ 横图             │  ← ShowThumbnailOrientation 控制
├──────────────────┤
│ 选中: 蓝色 4px   │  ← IsSelected=true 时显示
│ 边框 (#6366F1)   │
└──────────────────┘
```

**缩略图状态**：

| 状态 | 外观 |
|------|------|
| 加载中 | 显示确定性柔和彩色背景，文字显示 "加载中..." |
| 加载完成 | 背景色被图片覆盖，显示缩略图 + 文字叠加 |
| 选中 | 4px 蓝色边框 (#6366F1) 包围 |
| 相似图高亮 | 同上，使用 IsSelected 蓝色框 |

## 4. 主题系统

### 4.1 颜色定义

```csharp
// 深色主题 (默认)
AppBgBrush       = #1A1A24    // 应用背景
AppFgBrush       = #EAEAEA    // 应用前景
CtrlBgBrush      = #252536    // 控件背景
InputBgBrush     = #1A1A24    // 输入框背景
CtrlBorderBrush  = #35355A    // 控件边框
AccentBrush      = #6366F1    // 强调色 (靛蓝)
TextMutedBrush   = #909099    // 次要文字

// 浅色主题
AppBgBrush       = #F3F3F3
AppFgBrush       = #1A1A1A
CtrlBgBrush      = #FFFFFF
InputBgBrush     = #FFFFFF
CtrlBorderBrush  = #D0D0D0
AccentBrush      = #6366F1    // 强调色不变
TextMutedBrush   = #888888
```

### 4.2 搜索框边框颜色（动态）

| 搜索类型 | 边框颜色 | 含义 |
|----------|----------|------|
| AND | 绿色 #22C55E | `a 角色` - 同时包含 |
| AND-each | 蓝色 #3B82F6 | `e 角色` - 分别匹配 |
| NOT | 红色 #EF4444 | `- 废稿` - 排除 |
| 默认 | 控件边框色 | 无运算符或混合 |

### 4.3 共现标签状态颜色

| 循环状态 | 背景色 | 说明 |
|----------|--------|------|
| 第 1 次 (AND) | 浅绿 | 进一步限定 |
| 第 2 次 (AND-each) | 浅蓝 | 分别匹配 |
| 第 3 次 (NOT) | 浅红 | 排除 |
| 第 4 次 | 移除 | 从搜索条件中删除 |

## 6. 图片预览窗口

### 6.1 布局

```
┌─────────────────────────────────────────────┐
│  文件名.jpg — 1920×1080 — 2.5 MB      [_][X]│  标题栏
├─────────────────────────────────────────────┤
│                                     ▲       │
│   ◀                           ├──────┤      │  ← 左箭头 / 图片 / 右箭头
│                                     ▼       │     支持拖拽平移
├─────────────────────────────────────────────┤
│ 第 15/200 张  |  标签: 角色, 场景  |  150%   │  状态栏
└─────────────────────────────────────────────┘
```

### 6.2 缩放行为
- 滚轮以光标位置为中心缩放
- 缩放范围：`fitZoom * 0.05` ~ `10x`
- 步进：`1.15x` 每级
- 手动缩放后 `UserZoomed = true`，不再自动适应
- 双击重置为适应窗口

## 7. 标签编辑对话框

```
┌──────────────────────────────────────────────────────┐
│  编辑标签                                        [X]  │
├─────────────────┬────────────────┬───────────────────┤
│  自动补全建议    │  当前标签      │  收藏标签         │
│  (前缀匹配)     │               │                  │
│                 │  [角色] ×     │  ★ 角色          │
│  搜索: [____]  │  [场景] ×     │  ★ 场景          │
│                 │  [武器] ×     │  ★ 收藏          │
│  ┌───────────┐  │               │                  │
│  │ 角色 (45) │  │  [_________]  │  + 添加收藏      │
│  │ 场景 (32) │  │  [添加标签]   │                  │
│  │ 色气 (28) │  │               │                  │
│  │ ...       │  │  标签计数: ☐  │                  │
│  └───────────┘  │               │                  │
│                 │               │                  │
│  右键建议标签:  │               │                  │
│  ├── 重命名     │               │                  │
│  └── 合并到...  │               │                  │
├─────────────────┴────────────────┴───────────────────┤
│                              [确定]  [取消]           │
└──────────────────────────────────────────────────────┘
```

**交互逻辑**：
- 输入框键入 → 前缀匹配所有标签 → 显示在左侧建议列表
- 点击建议标签 → 添加到当前标签（取 tag 名，不含 count）
- 点击收藏标签 → 同上
- 当前标签 × 按钮 → 删除
- Enter 在输入框 → 添加自定义文本为新标签
- Enter 在空输入框 → 失焦 + 再次 Enter 关闭对话框 (OK)
- ToggleSwitch → 控制是否显示标签使用次数
- 右键建议标签 → 重命名 / 合并
