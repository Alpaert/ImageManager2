### 2.3 缩略图生成算法

```
Algorithm: Generate(filePath, decodeWidth) → byte[] (JPEG)

Input:  filePath - 图片路径
        decodeWidth - 目标宽度 (像素)

Output: JPEG 字节数组 (质量 85)

Procedure:
  1. 打开文件 → SKCodec.Create(filePath)
  2. 获取原始尺寸: codec.Info.Width, codec.Info.Height
  3. IF targetWidth >= originalWidth THEN
       a. IF originalWidth < 2 * targetWidth THEN
            RETURN 原图 JPEG 字节 (无需缩放)
       b. ELSE
            全分辨率解码 → Resize(targetWidth, linear过滤) → JPEG 编码
  4. ELSE (targetWidth < originalWidth)
       a. 计算 JPEG 原生缩放比例:
          jpegScale = 1
          WHILE (originalWidth / jpegScale) / 2 >= targetWidth AND jpegScale < 8:
            jpegScale *= 2
       b. codec.GetScaledDimensions(jpegScale) → 获取缩放后尺寸
       c. 以缩放比例解码 → 得到较小的 Bitmap
       d. Resize(targetWidth, 等比高度, linear过滤) → 精确目标尺寸
       e. JPEG 编码返回
```

### 2.4 感知哈希 - Walsh-Hadamard 变换

```
Algorithm: Hadamard2D(matrix[32][32]) → void (in-place)

Why: Walsh-Hadamard 变换仅使用加减法，无浮点乘法，
     比 DCT 快 5-10 倍，适合大规模批量计算

Procedure:
  1. 对每一行执行 Hadamard1D(row[32])
  2. 对每一列执行 Hadamard1D(col[32])

Hadamard1D(vec[n])  // n 必须是 2 的幂
  递推实现 (类似 FFT 蝶形运算):
  FOR step = 1; step < n; step *= 2:
    FOR i = 0; i < n; i += 2*step:
      FOR j = i; j < i+step; j++:
        a = vec[j]
        b = vec[j+step]
        vec[j] = a + b
        vec[j+step] = a - b
```

### 2.5 多哈希相似度投票

```
Algorithm: AreSimilarByMultiHash(combinedA, combinedB, aThr=8, dThr=8, pThr=10)

Input:  combinedA, combinedB - 格式 "aHash|dHash|wHash|histogram"
        aThr, dThr, pThr - 各哈希的汉明距离阈值

Output: bool - 是否判定为相似

Procedure:
  1. partsA = combinedA.Split('|')
  2. partsB = combinedB.Split('|')
  3. IF partsA.Length < 4 OR partsB.Length < 4 THEN RETURN false
  4. votes = 0
  5. IF HammingDistance(partsA[0], partsB[0]) <= aThr THEN votes++
  6. IF HammingDistance(partsA[1], partsB[1]) <= dThr THEN votes++
  7. IF HammingDistance(partsA[2], partsB[2]) <= pThr THEN votes++
  8. RETURN votes >= 2   // 2/3 通过
```

### 2.6 相似搜索二阶段过滤

```
Algorithm: FindSimilarAsync(basePath, candidates, threshold=5)

Input:  basePath - 基准图片路径
        candidates - 候选图片路径集
        threshold - 废弃参数 (保留兼容)

Output: List<string> - 相似图片路径

Procedure:
  1. hashCache = PreloadHashCacheAsync()
     // 从 DB 批量加载所有 PerceptualHash 到 ConcurrentDictionary

  2. baseHash = GetOrComputeBaseHashAsync(basePath)
     // 始终从文件重新计算，确保准确性
  3. baseHistogram = baseHash.Split('|')[3]

  4. results = new ConcurrentBag<string>()
  5. Parallel.ForEach(candidates, candidate =>
     {
       // 阶段 1: 直方图预过滤 (快速拒绝)
       candidateHash = GetCachedHash(candidate)
       IF candidateHash == null THEN return
       candidateHistogram = candidateHash.Split('|')[3]
       IF CompareHistograms(baseHistogram, candidateHistogram) < 0.35
         THEN return  // 不相似，跳过

       // 阶段 2: 多哈希投票
       IF AreSimilarByMultiHash(baseHash, candidateHash)
         THEN results.Add(candidate)
     })

  6. RETURN results.ToList()
```

### 2.7 设置序列化/反序列化

```
Algorithm: SaveAsync(AppSettings settings)

Procedure:
  1. await _saveLock.WaitAsync()
  2. conn.ExecuteAsync("DELETE FROM AppSetting")
  3. FOR EACH PropertyInfo prop IN typeof(AppSettings).GetProperties():
       key = prop.Name
       value = SerializeValue(prop.GetValue(settings))
       conn.ExecuteAsync("INSERT INTO AppSetting ...", {key, value})
  4. _saveLock.Release()

SerializeValue(object? value):
  IF value is bool b:     RETURN b ? "true" : "false"
  IF value is double d:   RETURN d.ToString(CultureInfo.InvariantCulture)
  IF value is int i:      RETURN i.ToString()
  IF value is string s:   RETURN s
  IF value is List<string> list:     RETURN string.Join("|", list)
  IF value is Dictionary<string,string> dict:
    RETURN string.Join("||", dict.Select(kv => $"{kv.Key}={kv.Value}"))
  ELSE: RETURN value?.ToString() ?? ""

LoadAsync() 是上述的逆过程，ConvertValue() 解析每种类型的字符串表示。
```

### 2.8 瀑布流布局算法

#### 垂直瀑布流 (Vertical Masonry)

```
Algorithm: ArrangeVertical(children, availableWidth, columnWidth)

  columnCount = max(1, floor(availableWidth / columnWidth))
  columnHeights = new float[columnCount]  // 初始为 0

  FOR EACH child IN children:
    // 找最短列
    shortestCol = argmin(columnHeights)
    x = shortestCol * columnWidth
    y = columnHeights[shortestCol]
    child.Arrange(new Rect(x, y, columnWidth, child.DesiredSize.Height))
    columnHeights[shortestCol] += child.DesiredSize.Height

  totalHeight = max(columnHeights)
```

#### 水平自适应 (Horizontal Justified)

```
Algorithm: ArrangeHorizontal(children, availableWidth)

  // 将子项分组为行，每行高度在 180~350px 范围
  rowItems = []
  currentRow = []
  FOR EACH child IN children:
    currentRow.Add(child)
    rowAspectSum = SUM(item.Width / item.Height FOR item IN currentRow)
    rowHeight = availableWidth / rowAspectSum
    IF rowHeight >= 180 OR rowHeight <= 350:
      确定该行，调整每个 item 宽度 = rowHeight * (item.Width / item.Height)
      currentRow = []
```

### 2.9 标签搜索 SQL 生成

#### AND 搜索 (requireAll = true)

```sql
SELECT DISTINCT im.FilePath
FROM ImageMeta im
JOIN ImageTag it ON im.Id = it.ImageMetaId
JOIN Tag t ON it.TagId = t.Id
WHERE im.FilePath IN @CandidatePaths
  AND t.Name IN @TagNames
GROUP BY im.Id
HAVING COUNT(DISTINCT t.Name) = @TagCount
```

#### OR 搜索 (requireAll = false)

```sql
SELECT DISTINCT im.FilePath
FROM ImageMeta im
JOIN ImageTag it ON im.Id = it.ImageMetaId
JOIN Tag t ON it.TagId = t.Id
WHERE im.FilePath IN @CandidatePaths
  AND t.Name IN @TagNames
```

#### 排除搜索 (NOT)

```sql
-- 子查询排除
AND im.FilePath NOT IN (
  SELECT im2.FilePath FROM ImageMeta im2
  JOIN ImageTag it2 ON im2.Id = it2.ImageMetaId
  JOIN Tag t2 ON it2.TagId = t2.Id
  WHERE t2.Name IN @ExcludeNames
)
```

#### 未标记搜索 (-every)

```sql
SELECT FilePath FROM ImageMeta
WHERE FilePath IN @CandidatePaths
  AND Id NOT IN (SELECT DISTINCT ImageMetaId FROM ImageTag)
```

## 5. 错误码

| 场景 | 处理方式 |
|------|----------|
| 文件不存在 | 跳过，从列表中移除 |
| 文件被占用 | 跳过一次，下次同步时重试 |
| 磁盘空间不足 | 缓存写入失败静默跳过，下次请求重新生成 |
| 数据库锁定 | SQLite WAL 模式自动重试，写操作 SemaphoreSlim 排队 |
| 标签重命名冲突 | 返回 RenameResult.Conflict，UI 提示用户 |
| HTTP 超时 | 30s 超时，静默失败 |
| 无效图片格式 | SkiaSharp 异常被捕获，跳过该文件 |
